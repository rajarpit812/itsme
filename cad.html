About model downloads

Each model opens in the Fusion web viewer. When creating its public share link, enable Allow item to be downloaded. Visitors can then use the viewer's Download menu to request an available CAD export format, including STL or STEP where supported. Fusion sends the generated download link by email (Autodesk documents a seven-day validity period); this is not the same as a direct, instant .stl or .step file URL.
